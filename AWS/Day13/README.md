### Cloud Watch

- Cloud watch is used to monitor all resources (ELB, S3, RDS, EC2 etc)
- IN cloud watch we create Alarms to monitor AWS resources
- Cloud Watch monitors the performance
- Two type of monitoring
  - Basic Monitoring : You will get the data points every 5 Mins, FREE
  - Details Monitoring: You will get the data points every 1 Mins, Billable
- With Cloud Watch you can monitor Applications also
